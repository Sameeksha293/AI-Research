📘 Security Learning Mode

Learn common coding vulnerabilities and how to prevent them.

1. Hardcoded Secrets

Risk: Passwords and API keys stored directly in source code.

password = "admin123"

Safer approach: Use environment variables.

import os
password = os.getenv("PASSWORD")

2. SQL Injection

Risk: Joining untrusted user input into a SQL query.

query = "SELECT * FROM users WHERE name = '" + username + "'"

Safer approach: Use parameterized queries.

cursor.execute(
    "SELECT * FROM users WHERE name = ?",
    (username,)
)

3. Unsafe eval()

Risk: Executing untrusted text as Python code.

result = eval(user_input)

Safer approach for integer input:

number = int(user_input)

4. Unsafe System Commands

Risk: Passing untrusted input to a shell command.

os.system(user_command)

Safer approach: Use a fixed executable and argument list.

import subprocess

subprocess.run(
    ["whoami"],
    check=True,
    shell=False
)
